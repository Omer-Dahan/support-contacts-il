## 4. מנוע החיפוש החופשי (FTS5)

לטובת שילוב בבוט טלגרם ובממשקים נוספים, הוטמעה תשתית חיפוש טקסטואלי מלא (Full-Text Search) המבוססת על מנוע ה-**FTS5** של SQLite.

### מאפייני המנוע:
1. **טוקניזציה ותמיכה בעברית:** שימוש ב-`tokenize='unicode61 remove_diacritics 2'` יחד עם פונקציית ניקוי לסימני ניקוד ותווי רוחב-אפס (`\u0591-\u05C7`, `\u200B-\u200F`).
2. **טיפול בתחיליות והטיות:** הרחבת שאילתות אוטומטית עבור ה' הידיעה (למשל `חשמל` ↔ `החשמל`), התאמת סיומות ורבים באמצעות wildcard (`חשמל*`), ושילוב ביטויי מחרוזת שלמה (`"תל אביב"`).
3. **משקולות רלוונטיות (BM25 Ranking):**
   - **שם חברה (`name`):** משקל 10.0 (עדיפות עליונה)
   - **שמות ערים וסניפים (`cities`):** משקל 6.0
   - **שם חוקי / רשמי (`legal_name`):** משקל 5.0
   - **קטגוריה (`category`):** משקל 5.0
   - **תוויות ומטרות טלפונים (`phone_labels`):** משקל 3.0
   - **תיאור חברה (`description`):** משקל 2.0
   - **סיכום AI לשירות (`ai_summary`):** משקל 2.0
4. **סנכרון אוטומטי מלא:** 8 טריגרים ב-SQLite מעדכנים את אינדקס ה-FTS5 בזמן אמת עם כל שינוי (`INSERT`/`UPDATE`/`DELETE`) בטבלאות `companies`, `branches` ו-`phones`.

## 5. מדריך שימוש בסקריפט החיפוש (`scraper/search.py`)

### שימוש משורת הפקודה (CLI):

```bash
# חיפוש חופשי לפי מילה
python scraper/search.py "חשמל"

# חיפוש לפי עיר / סניף
python scraper/search.py "תל אביב"

# חיפוש מורכב רב-מילים
python scraper/search.py "בנק מזרחי"

# חיפוש מילה הנמצאת רק בתיאור או בסיכום
python scraper/search.py "מזגנים"

# הצגת פרטים מלאים ומורחבים (כל הטלפונים, תיאור מלא ושעות פעילות)
python scraper/search.py "חברת החשמל" --details

# סינון משולב לפי קטגוריה ו/או עיר
python scraper/search.py --category "בנקים" --city "ירושלים"

# פלט בפורמט JSON (מושלם לאינטגרציה עם בוטים ו-APIs)
python scraper/search.py "בזק" --json
```

### שימוש כמודול Python (עבור בוט טלגרם):

```python
from scraper.search import search_companies, format_telegram_message, get_company_details

# 1. חיפוש חברות
results = search_companies("חשמל", limit=5)

for comp in results:
    # 2. עיצוב אוטומטי להודעת טלגרם מוכנה
    tg_msg = format_telegram_message(comp)
    print(tg_msg)
    print("---")

# 3. שליפת תיק חברה מלא (כל הטלפונים, סניפים, שאלות נפוצות)
details = get_company_details("bezeq")
print(f"סה\"כ מספרי טלפון: {len(details['phones'])}")
print(f"סה\"כ סניפים: {len(details['branches'])}")
```

## 6. סקריפט ייצוא ל-VCF (`export_vcf.py`)

הסקריפט מייצא אנשי קשר מותאמים לפורמט vCard 3.0 סטנדרטי התואם לסמארטפונים:
- תמיכה מלאה בסינון לפי קטגוריה: `--category` / `-c` (למשל `--category "בנקים"`).
- תמיכה בייצוא לפי slug ספציפי: `--slugs "bezeq,hot,partner"`.
- תמיכה בייצוא לפי חיפוש: `--query "חשמל"`.
- ייצוא מלא של כל המאגר: `--all`.
- רשימת כל הקטגוריות הקיימות: `--list-categories`.

```bash
# ייצוא קטגוריית בנקים לקובץ VCF
python export_vcf.py --category "בנקים" --output data/banks.vcf

# הצגת כל הקטגוריות ומספר החברות בכל אחת
python export_vcf.py --list-categories
```
